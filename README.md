# Конструктор ложемента для кейсов «Калибр»

Прототип веб-конфигуратора: клиент сам проектирует ложемент и отправляет заказ с чертежом.

Страница: https://romeo787ooo.github.io/lozhement-configurator/

## Что умеет

1. **Кейс.** 66 моделей «Калибр» с реальными внутренними размерами (данные caserf.ru, 10.2026), поиск по номеру и по аналогу Peli, подбор кейса по предметам.
2. **Предметы.** Два вида списка: дерево «кейс → крышка и основание → предметы» со свойствами и расположением каждого экземпляра, и карточки.
3. **Раскладка.** Авторасстановка с поворотом и выбором положения предмета, план 2D с перетаскиванием, 3D-модель кейса и ложемента.
4. **Заказ.** Оценка цены и пакет заказа: DXF для станка (слой на каждую глубину выреза), чертёж SVG с таблицей вырезов, состав заказа в TXT и JSON.

## Структура

`index.html` — разметка и стили. Скрипты подключаются обычными `<script>` по порядку и работают в общей области видимости, сборка не нужна.

| Файл | Что внутри |
|---|---|
| `js/data/catalog.js` | Каталог кейсов «Калибр»: размеры, глубины крышки и корпуса, аналоги Peli, цены дилера |
| `js/data/templates.js` | Шаблоны предметов, технологические параметры, материалы |
| `js/data/case-mesh-7030.js` | Встроенная сетка кейса 7030 для 3D |
| `js/core/orientation.js` | Положение предмета: на какую грань класть |
| `js/core/arrange.js` | Авторасстановка с подбором положения |
| `js/core/state.js` | Состояние и черновик в браузере |
| `js/core/geometry.js` | Ложемент, вырезы, глубины, контуры |
| `js/core/packing.js` | Раскладка вырезов (MaxRects, ряды одинаковых предметов) |
| `js/core/analysis.js` | Проверка раскладки |
| `js/core/pricing.js` | Оценка цены |
| `js/app.js` | Общий перерасчёт и перерисовка |
| `js/ui/step-case.js` | Шаг 1: выбор кейса |
| `js/ui/items-cards.js` | Шаг 2: предметы карточками |
| `js/ui/items-tree.js` | Шаг 2: дерево «кейс → крышка и основание → предметы» |
| `js/ui/step-params.js` | Шаг 3: технологические параметры |
| `js/ui/summary.js` | Сводка, статус, цена, шаги мастера |
| `js/ui/suggest.js` | Подбор кейса по предметам |
| `js/ui/layout.js` | Панели, разделители, полный экран |
| `js/ui/tools.js` | Сворачиваемые шаги, панель инструментов, контекстное меню |
| `js/view/plan-2d.js` | План 2D: отрисовка, перетаскивание, поворот |
| `js/view/view-3d.js` | 3D на WebGL |
| `js/view/case-model.js` | Точные модели и цвет кейса |
| `js/export/drawing.js` | Нумерация вырезов, DXF, чертёж SVG |
| `js/export/order.js` | Заказ, скачивание файлов, пакет ZIP |
| `js/main.js` | Запуск |

Порядок подключения важен: `state.js` при загрузке создаёт пример и поэтому идёт после `templates.js` и `orientation.js`, а `main.js` всегда последний.

## Ограничения прототипа

- Технологические параметры и тарифы условные, их нужно уточнить у производства.
- Отправка заказа менеджеру не подключена, пакет заказа скачивается файлом.
- Размеры шаблонов предметов примерные.
