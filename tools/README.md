# Подготовка модели Калибр 4035

Для посадки ложемента конвертер также сохраняет карты внутренней глубины основания
и крышки. Они вычисляются по первому пересечению луча от плоскости разъёма с корпусом
с шагом 2 мм и запасом 0,5 мм. Соседние отсчёты учитываются консервативно, чтобы
интерполяция у скруглений не выводила пену наружу.

В 3D нижняя поверхность и прилегающие стенки ложемента подстраиваются под эти карты
до поворота крышки. Карманы сохраняют координаты в плане; у стенок их видимая глубина
ограничена внутренней поверхностью корпуса. Это геометрия визуализации, а не
автоматическое изменение производственного чертежа.

Проверка на запущенном локальном сайте:

```powershell
python tools/check_foam_fit.py
```

Она сравнивает точки поверхности ложемента с пересечениями исходной сетки корпуса
в отдельном браузерном контексте, не меняя сохранённый пользовательский проект.

Модель в [case-mesh-4035.js](../js/data/case-mesh-4035.js) получена из предоставленной
сборки «Калибр 4035 с укладкой балон 3.STEP». Исходный STEP не изменяется
и не требуется для работы сайта.

Из 19 листовых компонентов исключены:

- 0 — укладка крышки;
- 15 — укладка основания;
- 16 — баллон.

К крышке отнесены компоненты 7, 11 (верхние крепления замков) и 17 (оболочка
крышки). Остальные сохранённые детали относятся к основанию.
Список компонентов и их исходные габариты записан в [4035-parts.json](4035-parts.json).
Индексы относятся только к этой конкретной сборке.

Конвертация: Python, `cadquery-ocp==7.8.1.1.post1`, `numpy`.

```powershell
python tools/inspect_step.py "путь/к/исходному.STEP"
python tools/convert_4035.py "путь/к/исходному.STEP"
```

Единицы — миллиметры. Допуск построения сетки — 0,3 мм, квантование — 0,01 мм.
Ось шарнира в исходной сборке проходит вдоль X при Y=171,75 и Z=0.
Ориентация преобразуется в формат существующего визуализатора: X — длина,
Y — вверх, Z — ширина. Модель хранится закрытой, крышка открывается рендерером.

Укладки из STEP не входят в модель корпуса. Ложемент, показываемый внутри
кейса, строится самим конфигуратором по текущей раскладке.
